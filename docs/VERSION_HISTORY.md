# Motion Log 버전 기록

앱 구조와 데이터 흐름의 변경 이력을 기록합니다.

## V2.2 · 운동 데이터 저장 규칙 표준화

- 운동 기록을 `한 운동 = 한 객체`인 평면(flat) JSON 레코드로 표준화
- 기존 웹앱 `Activity` 구조와 호환성을 유지해 기존 데이터의 대규모 마이그레이션을 피함
- 필수 필드를 `id / date / type / distanceKm / durationSec`로 명확히 정의
- 칼로리 / 걸음 / 페이스 / 속도 / 고도 / 고도 최소·최대 / 오르막·내리막 거리 / 심박 / 케이던스 / VO₂ Max 등을 선택 필드로 정의
- Samsung Health 화면에서 확인된 값만 저장하고 표시되지 않은 값은 생략
- 페이스는 초/km, 시간은 초 단위의 숫자로 저장
- 동일 운동 중복 저장 방지 규칙 명시
- 지도/그래프만으로 좌표나 세부 시계열 데이터를 임의 생성하지 않도록 규정
- `운동저장` 확인 후 `workout-data` 브랜치에 누적하는 현재 작업 흐름을 문서화

## V2.1 · 운동 데이터 GitHub 연동

- 운동 캡처 입력을 웹앱 OCR 방식에서 현재 Motion Log 대화방 기반 처리 방식으로 전환
- 운동 데이터 기준 브랜치를 `workout-data`로 분리
- 앱은 `workout-data`의 `public/motion-log-data-test.json`을 읽도록 변경
- 운동 데이터 변경만으로 Vercel 앱 코드를 다시 배포하지 않아도 되도록 데이터와 앱 배포를 분리
- 운동 데이터는 브라우저에 별도 캐시하지 않고 GitHub 기준 데이터로 직접 조회
- 운동 기록 추가 시 기존 ID를 변경하지 않고 새 기록만 누적
- 캡처에 표시되지 않은 값은 임의 생성하지 않음

## V1.1 · 운동 분석 개선

- 대시보드에 최근 7일 요약 추가
  - 운동 횟수
  - 총 거리
  - 총 운동시간
  - 평균 페이스 / 심박 / 케이던스
- 대시보드에 개인 기록(Personal Best) 추가
  - 최장 러닝
  - 최고 평균 페이스
  - 최고 평균 속도
  - 최장 운동시간
- 대시보드에 월간 리포트 추가
  - 현재 월 운동 횟수 / 거리 / 시간
  - 전월 대비 변화량
- 분석 탭에 러닝 `페이스 ↔ 심박` 산점도 추가
  - 현재 분석 기간을 따라 표시
  - 빠른 페이스와 낮은 심박의 위치 관계를 시각적으로 확인
- 좌측 브랜드를 `GALAXY WATCH FITNESS LOG`로 정리
- 한국어 우선 폰트 순서 조정
- 앱 화면에 현재 버전 표시
- JSON 백업 파일명에 앱 버전 포함
  - 예: `motion-log-v1.1-backup-2026-09-17.json`

## V2.3 · 데이터 흐름 및 UI 단순화

- 웹 기록 삭제/휴지통/복원/영구 삭제 기능 제거
- 브라우저 LocalStorage의 운동 기록 캐시 및 병합 로직 제거
- GitHub `workout-data`를 운동 데이터의 단일 기준으로 사용
- 설정의 JSON 복원 기능 제거, JSON/CSV 내보내기만 유지
- 모바일 하단 메뉴를 대시보드 / 기록 / 분석 / 설정 4개로 단순화
- 평균 페이스 집계는 총 운동시간 ÷ 총 거리 방식으로 계산
- 설정의 수동 동기화 명칭을 `GitHub 최신 데이터 불러오기`로 명확화
