# Motion Log 버전 기록

백업 파일과 화면 상태를 쉽게 구분할 수 있도록 앱 버전을 V1.0 → V1.1 방식으로 올립니다.

## V2.1 · 운동 데이터 GitHub 연동

- 운동 캡처 입력을 웹앱 OCR 방식에서 현재 Motion Log 대화방 기반 처리 방식으로 전환
- 운동 데이터 기준 브랜치를 `workout-data`로 분리
- 앱은 `workout-data`의 `public/motion-log-data-test.json`을 읽도록 변경
- 운동 데이터 변경만으로 Vercel 앱 코드를 다시 배포하지 않아도 되도록 데이터와 앱 배포를 분리
- 기존 LocalStorage 캐시 및 삭제 상태 보존 로직 유지
- 운동 기록 추가 시 기존 ID를 변경하지 않고 새 기록만 누적
- 캡처에 표시되지 않은 값은 임의 생성하지 않음

## V1.1 · 운동 분석 개선

- 대시보드에 최근 7일 요약 추가
  - 운동 횟수
  - 총 거리
  - 총 운동시간
  - 평균 페이스 / 심박 / 케이던스
- 대시보드에 개인 기록(Personal Best) 추가
  - 최장 러닝
  - 최고 평균 페이스
  - 최고 평균 속도
  - 최장 운동시간
- 대시보드에 월간 리포트 추가
  - 현재 월 운동 횟수 / 거리 / 시간
  - 전월 대비 변화량
- 분석 탭에 러닝 `페이스 ↔ 심박` 산점도 추가
  - 현재 분석 기간을 따라 표시
  - 빠른 페이스와 낮은 심박의 위치 관계를 시각적으로 확인
- 좌측 브랜드를 `GALAXY WATCH FITNESS LOG`로 정리
- 한국어 우선 폰트 순서 조정
- 앱 화면에 현재 버전 표시
- JSON 백업 파일명에 앱 버전 포함
  - 예: `motion-log-v1.1-backup-2026-09-17.json`

## V1.0 · 기준 버전

기존 Motion Log 기준 기능을 의미합니다.

- 대시보드 / 운동 기록 / 분석 / 휴지통 / 설정
- Samsung Health 데이터 동기화 및 LocalStorage 캐시
- 검색 / 정렬 / 종목 필터
- 기간 분석 및 사용자 지정 기간
- 거리 / 페이스 / 심박 / 케이던스 / 속도 / 칼로리 / 고도 추세
- 이전 동일 기간 비교
- 월별 거리 및 운동 캘린더
- 운동 상세 조회
- 휴지통 / 복원 / 영구 삭제
- JSON / CSV 백업 및 복원
- 다크 모드
